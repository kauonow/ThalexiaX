# Estrutura de Pastas

Cada coisa fica dentro da coisa maior onde está, e cada coisa tem a própria pasta. A estrutura é a mesma do vault do Mestre, para que publicar seja criar a nota no mesmo caminho.

```
notes/
  Thalexia - Início.md
  locations/   Regiões/Angra do Ferro/Cidades/(Cidade)/...
  npcs/        Globais/ Regionais/ Locais/
  factions/    (Facção)/Subfacções/(Subfacção)/
  lore/        Mundo/ História/ Fenômenos/ Lendas/ Crenças/
  deities/
  rules/
  maps/
```

Só entra aqui o que o povo sabe ou diz. Ver os hubs (`00 - ...`) de cada tipo.
